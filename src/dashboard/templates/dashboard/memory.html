Installed RAM Modules

Static hardware information from Windows

01

Available Memory

Available memory is the amount Windows can make available to applications without needing to page memory out to disk.

02

Working Set

A process working set is broadly the memory associated with that process that is currently resident in physical RAM. This is the process memory value used by Sys Monitor.

03

Caching

Windows can use otherwise idle RAM to keep recently useful data close to the CPU. Cached memory can often be reclaimed when applications need more memory.

04

Paging

Windows can use page files as part of its committed-memory system. A page file extends the amount of committed memory the system can support, but disk storage is far slower than physical RAM.
