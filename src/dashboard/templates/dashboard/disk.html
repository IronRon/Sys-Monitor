CAPACITY VS ACTIVITY

Two Different Measurements

01

Capacity Used

--%

This tells you how much of the filesystem contains stored data. It changes relatively slowly as files are created or deleted.

02

Disk Activity

MB/s

Read and write throughput tell you how much data is moving through storage during the current sampling interval.

STORAGE HARDWARE

Physical Drives

Static drive information discovered by Windows

01

Read

A read happens when data moves from persistent storage into memory so the computer can use it. Opening an application or loading a file can generate disk reads.

02

Write

A write happens when data is sent to persistent storage. Saving files, installing software and writing logs can generate disk writes.

03

Filesystem

A filesystem organises files and directories on storage. The C: capacity shown above refers to a filesystem volume rather than directly describing the entire physical device.

04

Physical Drive

A physical disk is the actual storage device. One physical drive can contain one or more partitions or volumes.
